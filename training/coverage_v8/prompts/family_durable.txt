TARGET FORM (family: durable-artifact-vs-streaming / R6): the boundary
between commands that CREATE a durable artifact and commands that only
STREAM data with nothing left behind. RULE: a command that creates a
durable artifact on disk or in a registry (installing a dependency tree,
cloning a repo, downloading a file, building an image, writing output to
a file via redirection or tee, uploading an object) is situation-normal
-- the backout is evident (delete it). A command that only streams data
to a terminal or a live connection with NO artifact left behind (reading
a file to stdout, curling a URL to stdout, following logs, watching a
process, listing) is informative. Include all of:
  - matched minimal pairs where only artifact-creation differs:
    `curl https://example.com/report.json` (informative, stdout only) vs
    `curl -o report.json https://example.com/report.json`
    (situation-normal, file written); `cat access.log` vs
    `cat access.log | tee /var/log/audit-copy.log`; `docker logs -f api`
    (informative, streaming) vs `docker build -t myapp:latest .`
    (situation-normal, image artifact).
  - package/dependency installs and builds (npm install, pip install -r
    requirements.txt, apt-get install, cargo build, bundle install, go
    build, docker build) as situation-normal.
  - pure log/metric streaming and tailing (tail -f, journalctl -f,
    docker logs -f, pm2 logs, watch, top, ps aux, curl to stdout with no
    -o/-O) as informative.
  - a few nested-interpreter hard negatives that still resolve on the
    artifact/streaming question, e.g. `bash -c "curl -o out.tar.gz
    https://example.com/archive.tar.gz"`, `sh -c 'pip install -r
    reqs.txt'` -- the outer shell wrapper does not change the answer,
    judge the inner command.
  - a couple of genuinely contested rows, e.g. `curl
    https://example.com/install.sh | bash` (executes unknown code but
    leaves no described artifact) -- mark contested=true with your own
    reasoned label in `note`.

Target label mix: ~42% informative, ~46% situation-normal, ~12%
data-critical (mostly the contested pipe-to-shell / risky-install cases).
contested ~15%.
